1. Nur **einen** Auftrag gleichzeitig an Codex übergeben. Einstieg: **AETH-00** als Bestandsaufnahme.
2. Nach Code-PR und lokaler Prüfung dieses Häkchen setzen und den Status in der Einzeldatei ändern.
